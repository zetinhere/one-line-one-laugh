A program that writes one funny line — a single joke that lands in one
breath — to `/output/entry.txt` for make.fun's "One Line, One Laugh"
bounty. The line was chosen by a proxy-judge tournament: twelve original
one-liners were played pairwise against each other and against two real
field entries, judged with the bounty judge's own published brief, and
the winner went in.

## Run it

```sh
python3 main.py
```

That writes the line to `/output/entry.txt` (or `./entry.txt` when
`/output` is not available, e.g. a local run).
